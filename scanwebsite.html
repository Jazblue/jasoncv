What can a basic website security check cover?

The exact checks depend on the website, its technology and the permission provided. A basic review may cover publicly observable security configuration and common web-security indicators.

01

HTTPS and browser security

Review whether HTTPS is in use and look for selected security headers and configuration issues that may deserve attention.

02

Clear findings report

Receive a concise explanation of the checks performed, observations, limitations and practical next steps — without unnecessary jargon.

03

Prioritised recommendations

Understand which findings may need attention first and when to involve your web developer or hosting provider.

Important: a basic check is not a full penetration test, compliance certification or guarantee that a website is secure. Automated tools can miss issues and can also produce false positives; findings need to be interpreted in context.

AI-assisted testing with Strix

Where appropriate for an agreed scope, I may use Strix as part of an AI-assisted security-testing workflow alongside other checks. The aim is to investigate potential issues and make the results easier to understand — not to treat tool output as proof on its own.

Permission first

Testing only starts after the site owner has authorised the agreed target and scope. No third-party site is tested without permission.

Human review

Potential findings should be checked and explained before being presented as confirmed vulnerabilities. No results are claimed here unless supported by an actual assessment.

Practical next steps

Recommendations are written for the site owner, with a clear distinction between observations, confirmed findings and items that need further investigation.

Frequently asked questions

Is £25 a full penetration test?

No. It is an introductory price for a limited basic check and summary. A full penetration test requires a separately scoped engagement.

Do you need permission to test my website?

Yes. The owner or an authorised representative must approve the target and scope before testing begins.

Will the check guarantee my site is secure?

No security check can guarantee that. The report describes the checks actually performed and highlights limitations as well as recommendations.

Can you fix issues as well?

Possible remediation can be discussed after the findings are reviewed. It is not included in the £25 basic check unless explicitly agreed in writing beforehand.
