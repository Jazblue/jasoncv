# JasonCV

A modern, interactive CV/portfolio showcasing Jason Harvey's professional background, skills, and achievements.

## Website

Visit the live site at: [jasoncv.click](https://jasoncv.click)

## Features

- Interactive portfolio with projects and experience
- Responsive design for all devices
- Modern tech stack (React, TypeScript, Tailwind)
- Smooth animations and transitions
- WCAG 2.1 AA compliance

## Project Structure

```
src/
├── components/
├── pages/
├── assets/
└── styles/
```

## Getting Started

```bash
git clone https://github.com/Jazblue/jasoncv
npm install
npm run dev
```
